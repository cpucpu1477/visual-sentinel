视觉哨兵 · 摄像头异常监控  使用说明
========================================

一、运行环境
- Windows 10 / 11
- 需要安装 Python 3.10 或更高版本（https://www.python.org/downloads/）
  安装时务必勾选 “Add python.exe to PATH”。

二、首次使用
1. 把整个文件夹解压到任意目录（路径尽量不要带特殊符号）。
2. 双击 “一键安装启动.bat”。
   首次会自动创建运行环境并联网安装依赖，需要几分钟，请耐心等待。
3. 安装完成后会自动弹出监控窗口，之后每次双击 “启动监控软件.bat” 即可。

三、使用步骤
1. 选择视频源：本地视频文件，或本机摄像头（填序号，一般 0 或 1）。
2. 点击“开始监控”。
3. 在右侧设置里按需开启并调整：
   - 黑屏 / 过曝 / 冻结 / 遮挡 / 画面剧变
   - 红绿颜色变化（指示灯变色）
   - 区域数值识别：先点“选择区域”框住数字，第一次识别值会自动作为基准，
     数值偏差超过阈值即报警。
   - 声音异常：环境音量过高或突发异响。
4. 报警会记录在下方列表，并保存截图到 data\snapshots 目录。

四、常见问题
- 提示未检测到 Python：安装 Python 后重新打开命令行或重启电脑使 PATH 生效。
- 依赖安装失败：检查网络，或改用手机热点重试；本包默认使用清华镜像源。
- 没有声音检测：确认电脑有麦克风，且系统已允许应用访问麦克风。
- 摄像头打不开：确认没有被其他软件（会议软件等）占用。
- 页面打不开 / 窗口空白：双击 “启动监控软件.bat” 重新启动；
  日志在 data\app.log。
- 端口被占用：程序会自动顺延端口，实际地址见 data\app.log。

五、数据说明
- 配置、报警记录、截图都保存在程序目录下的 data 文件夹。
- 卸载：直接删除整个文件夹即可，不会写入系统目录。
